[27/09, 8:33 pm] Deepu ❤️: # 🕹️ Tic-Tac-Toe Game

A clean, modern, and fully responsive implementation of the classic **Tic-Tac-Toe** (X and O) game built for the web.

## 🚀 Features
* **Responsive Design:** Fully optimized to be playable across all devices, including mobile, tablets, and desktops.
* **Interactive UI:** Smooth transitions, hover effects, and modern styling.
* **Win/Draw Detection:** Real-time logic checks for wins (horizontal, vertical, diagonal) and tie games instantly.
* **Score Tracker / Restart:** Easily reset the game board to keep playing multiple rounds.
* *(Optional)* **AI Opponent:** Single-player mode featuring a smart computer opponent (e.g., using the Minimax algorithm).

## 🛠️ Technologies Used
* **HTML5:** For semantic web structure and layout.
* **CSS3:** For modern custom styling and grid system layouts.
* **JavaScript (ES6):** For game engine architecture, event handling, and winning logic.

## 🎮 How to Play
1. The game is played on a grid that's 3 squares by 3 squares.
2. Player 1 is **X** and Player 2 (or the computer) is **O**. Players take turns putting their marks in empty squares.
3. The first player to get 3 of their marks in a row (up, down, across, or diagonally) is the winner.
4. When all 9 squares are full, the game is over. If no player has 3 marks in a row, the game ends in a tie.

An interactive, modern, and fully responsive implementation of the classic **Stone Paper Scissors** (Rock Paper Scissors) game. Play against a smart computer opponent and track your high scores in real time!

## 🚀 Features
* **Interactive UI:** Smooth button animations, hover effects, and visual cues for game choices.
* **Smart AI Opponent:** A randomized computer opponent that keeps the gameplay fair and unpredictable.
* **Live Scoreboard:** Tracks wins, losses, and ties dynamically throughout the game session.
* **Responsive Layout:** Optimized to look great on desktop monitors, tablets, and mobile smartphones.
* **Instant Reset:** A reset button to wipe scores clean and start a fresh session at any time.

## 🛠️ Technologies Used
* **HTML5:** Structuring the core elements, buttons, and display areas.
* **CSS3:** Custom styling, layouts (Flexbox/Grid), and transition animations.
* **JavaScript (ES6):** Game logic engine, user input handling, and dynamic DOM updates.

## 🎮 How to Play
1. Select your choice by clicking on either the **Stone**, **Paper**, or **Scissors** icon/button.
2. The computer will simultaneously make its random choice.
3. The winner is determined based on the classic rule set:
   * **Stone** beats **Scissors** (smashes it)
   * **Paper** beats **Stone** (covers it)
   * **Scissors** beats **Paper** (cuts it)
4. The scoreboard will instantly update to show who won the round.
